# NULL / VECTOR

미지의 신호를 관측하고 기록하는 정적 웹사이트입니다. 이전 대화의 원본 파일에 접근할 수 없어 요청된 동작을 기준으로 재구현했습니다.

## 실행 및 배포

`index.html`을 브라우저에서 열거나 정적 웹 서버로 제공하면 됩니다. 빌드와 패키지 설치가 필요하지 않습니다.

Cloudflare Pages에서 이 저장소의 `main` 브랜치를 선택하고 프레임워크는 None, 빌드 명령은 비워 두고 출력 디렉터리는 `.`으로 설정합니다.

## 기능

- 첫 화면에서 타겟이 약 5.6초 동안 움직인 후 중앙에 고정됩니다.
- 타겟 고정 전에는 ENTER가 비활성화되며, 고정 후 관측 대시보드에 진입할 수 있습니다.
- 레이더, 신호 파형, 최근 기록, 검색 가능한 아카이브, 기록 등록 화면을 제공합니다.
- 기록은 현재 브라우저의 localStorage에 저장됩니다. 서버 저장, 사용자 계정, 사용자 간 공유 기능은 없습니다. 브라우저 데이터를 삭제하면 기록도 삭제됩니다.
- 동작 줄이기 설정에서는 타겟 이동과 레이더 회전을 줄이지만 5.6초의 접근 대기 시간은 유지합니다.
- Google Fonts 연결이 불가능하면 시스템 글꼴로 표시됩니다.

샘플 기록 세 개와 레이더 신호는 화면 구성을 위한 예시이며 실제 관측 데이터가 아닙니다.
